Installing on Windows

Run the EXE installer. The MSI is available for managed Windows installs.

Windows may show a SmartScreen warning because the installer is not signed. Choose More info, then Run anyway.

Open the DMG and drag DBFlow into Applications. Pick Apple Silicon for an M1 or newer Mac, or Intel for an older one.

The app is not notarized. On first launch, right-click DBFlow and choose Open.

For AppImage, make the file executable and run it. On Debian or Ubuntu, install the DEB package. On Fedora, RHEL or openSUSE, use the RPM package.

Check the architecture shown next to each installer before installing on your device.

Installing on Windows

Run the EXE installer (the MSI is for managed installs). If SmartScreen warns that the installer is not signed, choose More info, then Run anyway.

Open the DMG and drag DBFlow into Applications: Apple Silicon for an M1 or newer Mac, Intel for older ones. The app is not notarized: the first time, right-click DBFlow and choose Open.

Make the AppImage executable and run it, or install the DEB (Debian, Ubuntu) or RPM (Fedora, openSUSE) package.

Open the APK and allow your browser or file manager to install apps when asked. Needs Android 7 or newer on a 64-bit ARM phone or tablet.
